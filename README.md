# FitBuddy 💪

FitBuddy is a simple fitness and health web application developed using Python and Flask.

## Features

- 🏠 Home page
- 💪 Workout recommendations
- 🥗 Diet recommendations
- 📊 Fitness result page
- ⚖️ BMI Calculator
- 📈 BMI Result page

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
